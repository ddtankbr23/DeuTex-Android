# DeuTex Android

Aplicación Android ARM64 para explorar y gestionar recursos WAD de Doom, Doom II, Heretic, Hexen y Strife.

## Estado

Primera base del proyecto: interfaz Android y lector WAD inicial. La integración completa del motor DeuTex original y las funciones de importación/exportación se incorporarán por etapas.

## Compilación

GitHub Actions compila el APK `arm64-v8a`. Consulta la pestaña **Actions** y descarga el artefacto `DeuTex-Android-debug` cuando termine correctamente.
